# Funds With Benefits

Directory of VCs, accelerators, angel networks, corporate VCs and sovereign funds that give founders benefits beyond capital.

- `index.html` — the site (static, no build step)
- `funds.js` — listed fund profiles (`[name, type, region, country, url, size, benefits, portfolio, news]`)
- Researched profiles (with sources) are inline in `index.html`.

Submissions: funds email meraj@code.in.

Deploys on Vercel as a static site from `main`.
